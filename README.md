## RFID-Based Inventory Management System 

Retail stores that rely on manual stock countin and spreadsheets frequently face with issue like stockouts ,overstocking and mismathes between the record and the content in the actualy inventory . Small errors compound to misplaced orders and would eventually cause loss . 

The Inventory Management system handles all the physical stock handling directly to the relational database, so that every addition or removal of the product would be captured at the moment it would happend rather then delaying it to be added later from manually written logs.

#### Objective :

1. Automate stock updates using RFID scanning in place of manual entry
2. Maintain a consistent, relational record of products, suppliers, and order
3. Give store staff a straightforward interface for everyday inventory tasks
4. Support reordering decisions through automatic low-stock detection
